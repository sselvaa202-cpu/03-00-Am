##  About the Project

**03:00 AM** is a creative web experience built around a single idea — **manifestation**: turning thoughts, imagination, and intention into something visual.

It's designed as a **frontend-only** website with no backend, database, or server-side logic — just clean HTML and CSS crafted to feel like a modern digital-art or creative-agency showcase, while keeping its own distinct branding, layout, content, and visual identity.

##  Getting Started

No backend, no build tools, no dependencies — just clone and open.

### 1. Clone the repository

```bash
git clone https://github.com/sselvaa202-cpu/03-00-Am.git
```

### 2. Navigate into the project

```bash
cd 03-00-Am
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run it

Open `index.html` directly in your browser — or, for a smoother dev experience, run it with the **Live Server** extension in VS Code for auto-reload on save.
